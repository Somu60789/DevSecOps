# Contributing

## Branch & PR rules

- Never push to `main`/`master`; always branch.
- Branches: `bot/docs-update`, `bot/devsecops-pipeline`, `bot/code-fix-YYYYMMDD`, `bot/pr-review-setup`.
- Every change lands via a pull request.

## Bot pipeline

Scan → triage → safe-auto-fix → optimize-suggest → continuous-docs → one consolidated PR comment.
